# Визуальное решение и техническая основа

Дата: 2026-10-06. Результат этапа 3 с уточнениями позиционирования салона.

Связанные документы: [план](DEVELOPMENT_PLAN.md), [проектная документация](PROJECT_DOCUMENTATION.md), [французская редакция](SITE_CONTENT_FR.md).

## Направление

Спокойная редакционная композиция с теплым светлым фоном, крупными заголовками с засечками, темно-зелеными блоками и приглушенными золотыми деталями. Золото поддерживает существующий логотип. Это выбранное агентом рабочее решение по поручению пользователя, а не отдельно утвержденный клиентом брендбук.

Первый экран представляет салон AM Beauty Concept и два направления: `Podologie` и `Remodelage de la silhouette`. Подология открывает перечень услуг; коррекция фигуры выделена следующим самостоятельным разделом. После подтверждения пользователем квалификации 2026-10-06 шесть карточек подологии включены в страницу.

## Композиция

- Шапка: существующий логотип, бренд, пять пунктов навигации и запись. На экранах до 1050 px меню раскрывается кнопкой.
- Первый экран: текст и декоративное изображение в двух колонках; на телефоне текст расположен выше изображения. Визуал оформлен аркой и тонким золотым контуром.
- Подология: заголовок и вводный текст, затем шесть карточек услуг. Сетка — три столбца на широком экране, два на планшете, один на телефоне.
- Фигура: темный блок, четыре описания с простыми декоративными SVG; на телефоне — один столбец.
- Салон: настоящий логотип, рядом описание направлений, адрес и обращение от лица салона. Имя в исходном логотипе сохранено; отдельного персонального блока нет.
- Пример работы: разрешенное фото целиком, без обрезки и изменения результата.
- Посещение: текстовый адрес и внешняя ссылка на маршрут. Встроенная карта не используется.
- Вопросы: нативные элементы `details` / `summary`, работают без JavaScript.
- Контакты: крупный призыв, WhatsApp, звонок, email и Facebook.
- На телефоне внизу закреплены звонок и запись; под контентом предусмотрен отступ. Предпочтение уменьшенного движения учитывается.

## Техническое решение

Статические HTML, CSS и JavaScript в `dist/`. Содержимое этой папки — готовая директория для статического размещения. Серверная обработка и библиотека интерфейса не нужны: страница показывает контент и открывает внешние средства связи.

По уточнению пользователя 2026-10-15 площадка размещения — GitHub Pages со статической директорией `dist`; публикацию выполняет `.github/workflows/pages.yml`. Ранее планировался Sites. На этапе 3 выполняется локальная работа: проект на хостинге не зарегистрирован, домен не куплен, публикация не выполнена. Перед выпуском потребуются домен / адрес и данные владельца сайта. Макет временно содержит `noindex, nofollow`; снять при подготовке публичного выпуска.

## Запуск и проверки

В корне проекта:

```bash
npm run dev
```

После запуска открыть `http://127.0.0.1:4173/`. Команда раздает только `dist/` на локальном интерфейсе. Остановка — `Ctrl+C`.

```bash
npm run check
```

Проверка использует Python 3 и Node.js. Пакеты устанавливать не нужно; отдельной сборки нет. В рабочей среде проверены Node.js 22.22.1 и Python 3.14.4. Без npm можно запустить `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`.

## Проверенный результат

На этапе 3 проверены HTTP 200, ссылки на ресурсы и якоря и французский язык HTML. В Chrome проверены 1440, 1024, 768, 390 и 320 px: изображения загружаются, горизонтальной прокрутки нет. Проверены меню, Escape с возвратом фокуса, закрытие меню при выборе раздела и FAQ. Без JavaScript навигация, содержание и ссылки записи доступны. Страница не загружает внешние ресурсы. Сообщения и звонки не отправлялись.
